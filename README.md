# Room Booking Application

Застосунок для зручного бронювання переговорних кімнат.

---

## Запуск проєкту

Для запуску проєкту потрібен встановлений **Docker** та **Docker Compose**.

```bash
# Збірка та запуск контейнерів у фоновому режимі
docker-compose up -d --build

```

Після успішного запуску додаток доступний за адресами:

* **Frontend:** http://localhost:3000
* **Backend API:** http://localhost:4000

---

## Застосування сідів (Seeders)

Щоб заповнити базу даних початковими даними (користувачі, кімнати, тестові бронювання), виконай команду всередині бекенд-контейнера:

```bash
docker exec -it room-booking_backend_1 npm run seed

```

## Перевірка перетинів та збереження часу

**Збереження часу:**
Усі дати та час зберігаються в базі даних виключно в форматі **UTC (ISO 8601)** (`YYYY-MM-DDTHH:mm:ss.sssZ`). Це гарантує незалежність від часових поясів сервера чи клієнта. Конвертація у локальний часовий пояс користувача відбувається на стороні фронтенду під час відображення.

**Перевірка перетинів бронювань:**
Логіка перевірки виконується на бекенді перед створенням або оновленням запису. Запит до бази шукає існуючі бронювання для цієї ж кімнати, де новий інтервал перетинається з вже наявним за умовою:
`НовийStart < ІснуючийEnd AND НовийEnd > ІснуючийStart`.
Якщо знаходиться хоча б один такий запис (і він не є поточним оновлюваним бронюванням), сервер повертає помилку конфлікту `409 Conflict`.
